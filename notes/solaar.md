## Buttons

| Solaar / internal name | Default / “friendly” name | Notes / behavior                                      |
| ---------------------- | ------------------------- | ----------------------------------------------------- |
| Left Button            | Left Click                | Standard left-click                                   |
| Right Button           | Right Click               | Standard right-click                                  |
| Middle Button          | Mouse Middle Button       | Usually the scroll wheel click                        |
| Back Button            | Mouse Back Button         | Thumb “back” button                                   |
| Forward Button         | Mouse Forward Button      | Thumb “forward” button                                |
| Mouse Gesture Button   | Gesture Button Navigation | Press + move gestures if set to “Mouse Gestures”      |
| Smart Shift            | Smart Shift               | Mode for scroll behavior (ratcheted / smooth)         |
| Virtual Gesture Button | Virtual Gesture Button    | A “virtual” gesture control internal to gesture logic |
